## Gotcha worth flagging

The naive `pathlib.Path(__file__).parent / 'version'` read of the version
file **breaks inside a zipapp** because the package isn't a real directory.
Switched to `importlib.resources.files(__name__).joinpath('version').read_text()`
which works on disk and inside a zip. The zipapp build job in `main.yml`
smoke-tests `python dist/sgi.zipapp --version`, so this would have failed
CI without the fix. Captured here so future spec packages don't repeat
the mistake when they read their own `version` files.
